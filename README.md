# LifeRPG

Консольный учебный прототип для тех, кто хочет развивать привычки и видеть
результат в виде прогресса персонажа. ПР3 объединяет работу с каталогом и
JSON из ПР2 с объектной моделью, опираясь на консольную программу ПР1.

## Запуск

Команды PowerShell из корня репозитория, Python 3.12.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe main.py --demo-pr01
```

Первый запуск открывает меню. Можно просматривать каталог, искать по названию,
фильтровать по категории, регистрировать активность по коду и смотреть прогресс,
историю и сводку. В демонстрации ПР1 ввод `350` даёт Силе уровень 3 и 50/300 XP.

## Выполнения и исправления

1. В меню выбери `2` и введи `training`. Повтори операцию.
2. Через `3` проверь Силу. Ожидается уровень 2 и 0/200 XP.
3. Через `4` найди номер выполнения. Выбери `5` и замени первое выполнение
   на `reading`. Ожидается уровень 1 и 50/100 XP у Силы.
4. Через `6` можно отменить выполнение по номеру. Через `8` видны
   исходные выполнения и все исправления, включая отмены.

Программа начисляет базовый XP из утверждённого каталога. Каждая характеристика
начинается на уровне 1 с 0 XP. Порог равен `100 × текущий уровень`, остаток
переносится. Сводка показывает число действующих выполнений и суммарный XP.

## Структура

| Файл | Ответственность |
|---|---|
| `main.py` | Меню, ввод и сообщения об ошибках |
| `character.py` | `Character` содержит шесть `Attribute`. Характеристика меняет XP через метод, а свойства дают доступ к уровню и XP на чтение |
| `activities.py` | `Activity` и `ManualXPAward` реализуют общий интерфейс `XPAction`. `ActivityCompletion` хранит ссылку на активность и снимок начисления. `ActivityLog` собирает записи и восстанавливает прогресс |
| `progression.py` | `xp_required` считает порог, `award_xp` начисляет XP с переносом остатка, `get_stat_progress` форматирует прогресс |
| `storage.py` | Проверка, загрузка и сохранение JSON, восстановление ссылок по кодам активностей |
| `tests/` | Проверки ПР1, объектов, исправлений и сохранения |

По умолчанию состояние хранится в локальном `data/state.json`. Можно указать
другой путь через `--state путь.json`. JSON версии 1 содержит номер записи,
код активности, сохранённые XP и признак исправления. Для отмены код равен
`null`, а начисление пустое. Новая поправка применяется к указанному номеру.
Прогресс восстанавливается из действующих начислений. Результаты других
выполнений берутся из их сохранённых значений. Повреждённый файл сохраняется
для диагностики. Запись производится через временный файл с последующей заменой.

## Проверка и отладка

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m flake8 . --extend-exclude=.venv,venv
```

Поставь точку останова в `Attribute.award_xp`. После двух регистраций
`training` открой характеристики и пошагово пройди второй вызов для Силы.
Наблюдай `amount`, `self._level` и `self._current_xp`. Они показывают переход
с уровня 1 и 50 XP на уровень 2 и 0 XP. После исправления повтори проверку.
В `load_log` можно проследить, как код активности становится ссылкой на объект.

## Дальнейшие практические

Для каждой номерной ПР сверять обязательные условия с оригинальной методичкой,
проверять сохранение предыдущего функционала и отражать результаты каждого
пункта в отчёте. Следующие этапы проекта включают Django, SQLite, ORM,
административный интерфейс и формы.
