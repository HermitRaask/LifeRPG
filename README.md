# LifeRPG

## Назначение

LifeRPG помогает отслеживать личный прогресс, превращая повседневные
действия в развитие игрового персонажа.

## Целевая аудитория

Люди, которые хотят развивать привычки и видеть свой прогресс в игровом формате.

## Предметная область

Действия пользователя развивают характеристики персонажа. Каждая характеристика
начинается с уровня 1 и 0 XP. Для перехода на следующий уровень нужно
`100 × текущий уровень` XP. Остаток переносится на новый уровень.

## Основные сущности

- Персонаж с шестью характеристиками — Сила, Ловкость, Выносливость,
  Интеллект, Творчество и Воля.
- Характеристика с собственным уровнем и текущим XP.
- Начисление XP к выбранной характеристике. В демонстрации ПР1 это Сила.

## Основные функции

- `xp_required` вычисляет порог следующего уровня.
- `award_xp` начисляет XP, повышает уровень и переносит остаток.
- `get_stat_progress` показывает уровень, текущий XP и порог следующего уровня.

## Запуск ПР1

Рабочая ветка — `feature/pr01`. Команды для PowerShell из корня репозитория.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe main.py
```

Введи `350`, чтобы получить результат `Сила: уровень 3, 50/300 XP`.
Состояние демонстрации сбрасывается при каждом запуске.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m flake8 . --extend-exclude=.venv,venv
```

Для проверки отладки выбери интерпретатор из `.venv` в IDE, поставь точку
останова на условии цикла в `award_xp` и запусти `main.py` с вводом `100`.
Проследи значения `level`, `current_xp` и `required` до и после повышения.
