# LifeRPG

LifeRPG — трекер привычек, позволяющий превратить свою жизнь в игру. Повседневные дела развивают
характеристики, наглядно демонстрируя отдачу от каждого действия. Отмечай тренировки, учёбу, работу над хобби и другие
активности, получай опыт и следи за своим прогрессом. Приложение работает
локально и без доступа к сети, данные хранятся на устройстве.

## Запуск

Запуск происходит через запуск файла LifeRPG.exe в корне проекта. Программа откроется
в собственном окне Windows. Прогресс сохраняется
после каждого подтверждённого действия.

Для запуска нужен установленный в Windows Microsoft Edge WebView2 Runtime.

## Первое действие

1. На странице **«Обзор»** или **«Активности»** необходимо выбрать выполненную активность.
2. Затем нужно указать интенсивность и нажать **«Рассчитать награду»**.
3. После предварительного расчёта программа покажет,
   сколько XP получила каждая характеристика и какие уровни повысились.

## Основные возможности

- **Характеристики.** Каждый пользователь имеет свои показатели Ловкости, Выносливости, Интеллекта,
  Творчества и Воли. На главном экране видны уровень и опыт до следующего
  повышения. Интенсивность, повторы за игровой день и активные перки
  влияют на награду.
- **Навыки и достижения.** Меню навыков даёт возможность увидеть освоенные навыки.
  Достижения отмечают игровые вехи, позволяя увидеть пройденный путь.
- **Задания и серии.** Ежедневные и еженедельные задания помогают привить себе полезные привычки.
  Регулярное выполнение продлевает серию, а заморозки и «Последний шанс»
  могут сохранить её при пропуске.
- **Перки и модификаторы.** Каждый человек уникален, кажая история неповторима.
  Добавьте собственные качества, которые повлияют на получение опыта в категориях.
  На главной странице можно посмотреть их
  состояние и эффекты.
- **История.** Можно посмотерть все выполненные активности и начисления по
  характеристикам. В течение часа после записи активность можно исправить
  или отменить. При этом корректируются XP характеристик и счётчики
  повторов. Уже записанные навыки, задания, серии и достижения сохраняются.
- **Отчёты.** Можно выбрать период для просмотра статистики. В разделе также
  появляются отчёты за завершённые игровые недели и месяцы.
- **Настройки и резервное копирование.** По умолчанию игровой день
  начинается в 04:00 по московскому времени. Часовой пояс и начало дня
  можно изменить до первой активности. Здесь же можно создать резервную
  копию журнала.
- **Режим разработчика.** Позволяет задать новые, актуальные для вас
  активности, модификаторы и достижения. Даёт возможность тонко настроить
  приложение под себя, задав начальные параметры и количество необходимого
  для повышения опыта.

## Сохранение

Ярлык открывает сохранение из папки проекта. События записываются в
`data/web/events.jsonl`, состояние и отчёты доступны через `db.sqlite3`.
Копии журнала сохраняются в `data/web/backups/`.

## Для разработчиков

Консольная точка входа находится в `main.py`, Windows-оболочка — в
`desktop.py`. Команды запуска веб-версии, восстановления и тестирования
описаны в [технической документации](docs/WEB.md).

Сборка для Windows из корня проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm LifeRPG.spec
```

Готовая сборка появится в `dist/LifeRPG/`. Для обновления версии в корне
проекта закрой приложение и замени EXE и папку `_internal` из новой сборки.
